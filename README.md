# منصة سفير الثقافة المؤسسية

تطبيق ويب عربي RTL لتخطيط برامج الثقافة المؤسسية وتوثيق الأنشطة والإنجازات والشواهد. أُنشئ المشروع من البداية داخل مستودع `alsaabxa/safeer`، ويرتبط بمشروع Firebase ذي المعرّف `safeer-f0303` واسمه الظاهر `safeer`.

## الوظائف

- حسابات مستقلة عبر Firebase Authentication بالبريد وكلمة المرور، مع إعادة تعيين كلمة المرور.
- لوحة متابعة وكتالوج برامج مؤسسية.
- بيانات السفير/ة والمدرسة.
- خطة تشغيلية بمستند مستقل لكل نشاط وتحديث حالته.
- استيراد خطة سفراء الثقافة لعام 2026، وتتضمن 24 نشاطًا موزعة على الأيام العالمية والقيم المؤسسية وحياك والتواصل الملهم ونهتم بك والابتكار ومزايا والصحة التنظيمية.
- لكل نشاط في خطة 2026 توقيت وفئة مستفيدة وطريقة تنفيذ وشواهد مقترحة، مع حالة متابعة وتاريخ إقفال.
- تقارير بمستند مستقل لكل تقرير، مع رابط اختياري للشواهد الرقمية.
- سجل شواهد مستقل بروابط المشاركة، مع حذف السجل.
- ملف إنجاز يجمع البيانات والخطة والتقارير للطباعة أو الحفظ PDF.
- استعلام زمني مقسّم إلى صفحات من 40 مستندًا؛ استخدم «تحميل سجلات أقدم» لعرض السجلات السابقة.

## هيكل Firestore

```text
users/{uid}/profile/main
users/{uid}/plans/{planId}
users/{uid}/reports/{reportId}
users/{uid}/evidence/{evidenceId}
```

كل مستخدم له مجموعات فرعية خاصة، وكل سجل مستند منفصل. تُحفظ بيانات السجلات وروابط HTTPS للشواهد في Firestore. تُرفع ملفات الشواهد إلى خدمة خارجية مثل مساحة المدرسة أو Google Drive ثم يُحفظ رابط المشاركة.

تُستورد أنشطة خطة 2026 إلى `users/{uid}/plans` بمعرفات ثابتة داخل حساب المستخدم؛ لذلك لا تتكرر عند إعادة الاستيراد ولا تتشارك المدارس بيانات بعضها. يمكن تسجيل كل مستند أو صورة أو عرض كشاهد مستقل، مع رابط مشاركة آمن. ويُبنى ملف الإنجاز من بيانات المدرسة والخطة والتقارير والشواهد المسجلة.

## خطة سفراء الثقافة 2026

تستند القوالب التشغيلية إلى «دليل تنظيم ملف سفير الثقافة المؤسسية 2026» و«الخطة التشغيلية لسفراء الثقافة بالمدارس». بعد تسجيل الدخول افتح **الخطة** ثم اختر **تحميل خطة 2026**. ستُضاف الأنشطة الآتية لكل حساب على حدة:

1. الأيام العالمية: الإسعافات الأولية، الزهايمر، الصحة النفسية، التوعية بسرطان الثدي، السكري، حقوق الإنسان، والعصا البيضاء.
2. القيم المؤسسية: الجودة، الالتزام، العمل الجماعي، الإبداع، والتعلم المستمر.
3. ملتقى الهوية المؤسسية، والتقرير الختامي لقيم 2026.
4. حياك: تهيئة الموظف الجديد.
5. التواصل الملهم: اللقاءات الرسمية الدورية، الموظف الضيف، القائد الموجّه، جلسة القهوة، واللقاء الداخلي غير الرسمي.
6. نهتم بك: رسائل وبطاقات المناسبات الشخصية.
7. الابتكار: تكريم مبادرات الموظفين المبتكرة.
8. مزايا: مشاركة العروض الشهرية.
9. الصحة التنظيمية: الرسائل والممارسات التوعوية وفق الخطة.

يُظهر كل صف طريقة التنفيذ والشواهد المقترحة. عند إكمال النشاط، حدّث الحالة إلى «مكتمل» ثم أدخل تاريخ الإقفال. ويمكن إضافة التقارير والشواهد مرارًا لتوثيق عدة مستندات لنشاط واحد. تشمل قائمة الشواهد المعتادة: عنوان النشاط وتاريخه وهدفه وفئته، آلية التنفيذ، الإعلان أو التصميم أو العرض، صور التنفيذ، النتائج والأثر، واعتماد التقرير وفق إجراء المدرسة.

## الإعداد المحلي

1. مشروع Firebase هو `safeer-f0303` (الاسم الظاهر `safeer`). قاعدة `safeer-main` موجودة في `me-central2` (الدمام) بإصدار Enterprise Native. Cloud Firestore يوفر حصة مجانية ضمن Spark؛ تنطبق حدود الحصة، وبعدها يتوقف الاستخدام على Spark حتى ترقية المشروع.
2. Firebase Storage غير مستخدم لأن إنشاء أو استخدام مخزن Firebase يتطلب خطة Blaze. استخدم رابط HTTPS لشاهد محفوظ في مساحة خارجية.
3. ملف `firebase.json` يفعّل Email/Password عند نشر إعداد Authentication.
4. أضف `localhost` ونطاق الاستضافة إلى Authorized domains في Authentication.
5. انسخ إعدادات تطبيق الويب إلى `.env.local` (مستثنى من Git).
6. ثبّت Node.js 20.19+ أو 22.12+، ثم شغّل:

```bash
npm install
npm run dev
```

إذا لم تُضف إعدادات Firebase، يعرض التطبيق صفحة تشرح أسماء المتغيرات الناقصة.

## نشر Firebase

لنشر الاستضافة وقواعد Firestore وإعداد Authentication على Spark:

```bash
npx firebase-tools login
npx firebase-tools use YOUR_FIREBASE_PROJECT_ID
npm run build
npx firebase-tools deploy --only firestore,auth,hosting
```

ملف `.firebaserc` مضبوط على `safeer-f0303`. لا ترفع `.env.local` أو مفاتيح حساب الخدمة إلى Git. تعتمد الشاشات على مستمعي `onSnapshot` للتحديث الفوري مع ترقيم النتائج إلى صفحات من 40 مستندًا.

## حدود ومراجعة قبل الإطلاق

- التسجيل الذاتي مفعّل. إذا كانت الحسابات تتطلب موافقة مسؤول، أضف سير اعتماد موثوقًا عبر Cloud Functions وCustom Claims قبل الإطلاق.
- قواعد Firestore تقصر المستندات على المستخدم صاحب الحساب وتتحقق من الحقول والأطوال وصيغ روابط الشواهد. احرص على متابعة استهلاك الحصة المجانية.
- تعرض لوحة المتابعة عدد السجلات المحملة في الصفحة الحالية؛ السجل نفسه يدعم جلب الصفحات الأقدم.
